# Start here (judges)

**What it is.** Kiroween Chaos is chaos engineering for AI agents, played as a haunted house. It crashes and curses your bots, grades how they survive from the provider's own ledger, and writes a fix spec for what broke. Fixes are never applied automatically; a person reviews them.

**Try it.**

- Hosted, no install: https://kakoritz.github.io/Kiroween-Chaos-Official/ (the tournament, Casebook and improve loop replay recorded runs of the real engine, and a banner says so).
- Real engine, two commands (Node 20+, Python 3.12 for the Ticket Desk):

```
npm ci
npm run demo
```

The tour is in [`JUDGES.md`](JUDGES.md). To run your own bot instead: [`OWN-BOT.md`](OWN-BOT.md), five minutes.

## The three apps

| App | Language | Stages | Folder |
|---|---|---|---|
| Orders | Node | 11 | `apps/haunted-orders/` |
| Ticket Desk | Python | 11 | `apps/haunted-inbox/` |
| Stream | Node | 5 | `apps/haunted-stream/` |

The arena's app switcher labels them Haunted Orders, Haunted Inbox (the Ticket Desk) and Haunted Stream. All three run on one skeleton, `packages/haunt/`, with no engine change.

**Any app plugs in.** Two more apps are one config file each: Haunted Playback (11 viewer stages, `apps/haunted-playback/`) and the Coffee Shop (`examples/coffee-shop/`). Yours is a `haunt.yaml` too. Start with [`MODULAR.md`](MODULAR.md) (how it works) and [`INTEGRATE.md`](INTEGRATE.md) (five steps). The Chain Wizard (`/chain.html`) tests one block alone, then chains blocks and says which one broke it. Questions you may have: [`JUDGE-QA.md`](JUDGE-QA.md); my own scoring of the project: [`JUDGE-CHECK.md`](JUDGE-CHECK.md).

## How to read TRACE.md

[`TRACE.md`](TRACE.md) is generated by `npm run trace`. The coverage block at the top counts requirements and tasks with a PR or a test. Each task row lists its spec, status, linked PRs and the tests whose `// covers:` comment names it. A `-` means no link of that kind, not a failure. Every requirement has a test; PR links are lower because early work did not name task IDs.
